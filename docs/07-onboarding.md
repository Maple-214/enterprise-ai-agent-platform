# 07 - Onboarding

新同学第一次进入项目：

1. 阅读 README
2. 启动 Docker
3. 登录 Demo
4. 完成 Calculator Tool
5. 上传知识库
6. 阅读 Agent Runtime
7. 阅读 Security
8. 再开始修改代码

## 第一个 PR

建议从以下任务开始：

- 增加一个简单 Tool
- 增加一个 Knowledge API 字段
- 增加一个前端 Agent Event UI
- 增加一个 Evaluation Case

不要一上来改 Runtime Core。

## PR 描述应至少包含

```text
Problem
Solution
Tests
Security Impact
Migration Impact
Observability Impact
```
